# Пре-регистрация ворот v3 (эпоха-3)

Дата фиксации: 2026-07-31. Пороги выбраны по кривым стенда `calibrate.ts`
(сетка истины μ × ρ, 400 потоков/ячейку, сид 20260731) ДО внедрения в
производство. Менять их после взгляда на живые прохождения запрещено — это
и есть пре-регистрация.

## Измеренный приговор текущим воротам (эпоха-2)

| Ворота | Ложный проход (μ=0) | Recall μ=0.10R | Recall μ=0.15R |
|---|---|---|---|
| nullTop5 (медианный z≥3, top-5 симв.) | 0.000 | **0.000** | **0.000** |
| breadth (доля ≥ 0.6) | 0.06–0.07 | 0.95–0.98 | 1.00 |
| DSR (эпоха-2: N=4700, разд. партии 0.0063) | 0.00 | 0.00 | 0.00 |

`gate_null` неспособен пропустить край ЛЮБОГО реалистичного размера —
единственный кандидат за жизнь, дошедший до DSR, был статистическим чудом.
Все 24 370 смертей эпох 1–2 несут этот артефакт.

## Решение v3 (зафиксировано)

1. **Главный статистический тест** — замена gate_null:
   - Базлайн: K=20 прогонов случайных входов, СОХРАНЯЮЩИХ РАСПИСАНИЕ
     кандидата (совпадающее распределение день-недели × час; тот же движок
     выходов). Сохранение расписания убирает две халявы разом: сезонность
     больше не получает z даром (её базлайн входит там же, где она), а
     лонг-на-росте не проходит за счёт беты (базлайн ловит тот же дрейф).
   - Статистика: дневные ПОРТФЕЛЬНЫЕ net-доходности кандидата минус средние
     дневные базлайна → t = mean·√days / sd по этому разностному ряду.
     Кластеризация по дням обязательна: при ρ=0.6 внутри дня пул сделок
     лжёт о числе независимых наблюдений.
   - **Порог: t ≥ 2.6, минимум 60 непустых дней.**
   - Измерено стендом (аппроксимация без базлайна, нулевой дрейф):
     ложный проход 0.01; recall 0.85 (ρ=0.6) / 0.97 (ρ=0.3) на μ=0.10R;
     0.24–0.36 на μ=0.05R. Край тоньше 0.05R мы сознательно не ловим —
     он не окупает издержки исполнения.

2. **Широта** — без изменений (доля прибыльных символов ≥ 0.6): измеренная
   характеристика приличная, не узкое место.

3. **Плато** — добавить абсолютный допуск: пик против медианы соседей
   карается только при |кандидат − медиана| > 0.05R (сейчас 74 из 117
   смертей плато — «слишком хорош» на шумной медиане 16 символов).

4. **DSR** — пересчитать пороговую кривую стендом ПОСЛЕ внедрения пп.1–3 на
   чистой дисперсии партии эпохи-2 (фикс stageASharpes уже в бою); до тех
   пор ворота остаются как есть. Отдельная пре-регистрация.

5. **Инкубатор** — порог входа в единицах δ = μ₁/σ: δ ≥ 0.18
   (E[N] ≤ 150 при α=0.05, β=0.1), потолок сделок = 3·E[N] без жёсткого
   cap=150. Текущая пара (0.20R; cap 150) даёт 98–99.7% «усечения» при
   любой истине — тест, который не может закончиться.

## Контроль после внедрения (A/B-мост)

1–2 ночи старых семейств через ворота v3. Ожидание: почти-ноль валидаций
(WRC p=0.7–0.97 говорит, что в старом классе края нет). Если старый класс
вдруг начнёт «валидироваться» пачками — v3 откатывается, порог
пересматривается ВВЕРХ; сами пороги по живым данным не трогаются.

## Что стенд НЕ моделирует (честные границы)

- Дрейф символов (μ базлайна ≠ 0) — поэтому в проде тест обязан быть
  разностным с базлайном, а не голым t (стенд голого t это не отличит).
- Хвосты распределения R (тейк/стоп-структура) — нормальное приближение;
  порог 2.6 консервативнее номинального p≈0.005 на тяжёлых хвостах.
- Автокорреляцию дней — при необходимости добавить блочный бутстреп в
  следующей ревизии стенда.
