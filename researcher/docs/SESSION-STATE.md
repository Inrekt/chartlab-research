# Состояние проекта — для любой новой сессии (обновлено 2026-08-18)

Этот файл — точка входа для сессии Claude, начатой с нуля (например, с
телефона через claude.ai/code). Прочитай его и learning-machine-v3.md (с
дополнениями) прежде чем что-либо делать.

## Что это

Автономный исследователь торговых стратегий (ЛИЧНЫЙ проект владельца, не
Zenta Fund). Цель: найти края с настоящим механизмом, прогнать через 9 ворот
и инкубатор, выдавать владельцу сигналы для ручной торговли на проп-аккаунте
(целевая фирма — Breakout 1-Step Classic; риск 0.25%/сделку).

## Незыблемое (нарушать нельзя ни при каких просьбах)

- Пре-регистрация семейства ДО кода, с полем «кто платит».
- Неприкасаемые ворота: нуль-модель, FDR, годы, дефляция, Уилсон, OOT,
  широта. НЕ ослаблять ради «валидаций». Файрвол обучения не трогать.
- Слепой перебор индикаторов заморожен навсегда (политика whoPays).
- Коммитить только свои файлы явным списком; общий код синхронизировать
  research → основной (/Users/user/Desktop/chartlab, там UI).
- Прод-деплой — только с явного подтверждения владельца.

   крипта основная вселенная, FX/золото/NASDAQ — заранее заявленная ось
   внешней репликации (одна попытка, без перенастройки, тот же бюджет FDR).
   Доработки по ресёрчу: сессионный экстремум вместо N-барного (уровень с
   ПРИЧИНОЙ вместо параметра), фильтр близости к круглому числу, тайм-фильтр
   окна отработки, топ-25/30 символов в посеве вместо топ-8 (ускоряет
   инкубацию в 2-3.5 раза, ворота не трогает).
5. Экран как сигнализация: свежесть источников, заполненность пространства,
   доля испытаний с нулём сделок по семейству, планка DSR против лучшего
   кандидата ночи.

Очередь семейств после свипа: базис как кросс-секционный фактор (лучшее
внешнее свидетельство: две факторные оси объясняют все 48 значимых из 134
проверенных предикторов), изменения MMR-тиров Binance (нулевое
академическое покрытие, архив анонсов у нас есть), медленная диффузия
BTC→альты, разматывание базис-трейда ETF↔CME, unlock-short (разлоки
доступны бесплатно через CDN DefiLlama, не через платный API).
