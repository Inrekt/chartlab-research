# Состояние проекта — для любой новой сессии (обновлено 2026-08-07)

Этот файл — точка входа для сессии Claude, начатой с нуля (например, с

## Что это

Автономный исследователь торговых стратегий (ЛИЧНЫЙ проект владельца, не
Zenta Fund). Цель: найти края с настоящим механизмом, прогнать через 9 ворот
и инкубатор, выдавать владельцу сигналы для ручной торговли на проп-аккаунте
(целевая фирма — Breakout 1-Step Classic; риск 0.25%/сделку).

## Незыблемое (нарушать нельзя ни при каких просьбах)

- Пре-регистрация семейства ДО кода, с полем «кто платит».
- Неприкасаемые ворота: нуль-модель, FDR, годы, дефляция, Уилсон, OOT,
  широта. НЕ ослаблять ради «валидаций». Файрвол обучения не трогать.
- Слепой перебор индикаторов заморожен навсегда (политика whoPays).
- Коммитить только свои файлы явным списком; общий код синхронизировать
  research → основной (/Users/user/Desktop/chartlab, там UI).
- Прод-деплой — только с явного подтверждения владельца.

- Экран: вкладка «Хедж-фонд → Исследователь» в основном репо.

### Починено 2026-08-08 (аудит + адверсарная перепроверка)
- **Фандинг был НЕВИДИМ в облаке**: COLLECT_DIR отсутствовал в nightly.yml и
  hourly.yml → 212 испытаний funding_pressure со 100% нуля сделок и ложный
  вывод «фандинг не работает» + поднятая планка дефляции всем остальным.
- **Гэп через стоп** исполнялся по цене стопа, которой в баре не было —
  левый хвост убытков обрезан по построению (engine.ts).
- **Предполётная проверка источников** (preflight.ts): нет каталога → прогон
  падает, а не пишет ноль сделок как вывод о рынке. Сразу вскрыла, что
  metrics-1h, архив анонсов и снимки биржи существовали ТОЛЬКО на маке.
- **Журнал не теряется при падении** (if: always() на коммит).
- **Недобор партии кричит и останавливает прогон**; добавлен
  fundableSpaceSize() = 468 комбинаций на ТФ.
- **Журналов было ДВА**: локальный дефолт ~/.chartlab/data (6231 кандидат) и
  облачный <repo>/ledger (56374) — раздвоенный счёт попыток = сломанная
  дефляция. Дефолт переведён на зеркало data-репо.

### 🔴🔴 ГЛАВНОЕ: корпус был СПОТОВЫЙ, а не перпы (найдено 2026-08-08)
Сверка байт в байт на BTC/ETH/SOL/AAVE/WIF: свечи корпуса совпадают с
`api.binance.com/api/v3` (спот) и НЕ совпадают с `fapi` (перпы). При этом
фандинг, OI, long-short и поток тейкеров — фьючерсные, документация всюду
говорит «перпы», а владелец будет торговать перпы на проп-аккаунте.
**Цена бралась с одного рынка, микроструктура — с другого**, и сильнее всего
это било по единственным семействам с бюджетом (ликвидити-магнит, фандинг):
их механизм — ликвидации и плечо, а на споте плеча нет.
Живая догонка инкубатора (`binance.ts`) тоже спотовая — паритет
«бэктест ↔ инкубатор» цел, но оба меряют не тот рынок.

Причина «истории с 2021» тоже вскрыта: 44000 часов от 2021-07-11 дают ровно
2026-07-25 (дату сбора) — потолок отсчитан НАЗАД, это не предел данных.

Написан `researcher/collect-candles.ts`: фьючерсы по умолчанию, без потолка,
дозапись хвоста, манифест версии. Переход РАСШИРЯЕТ окно поиска — фьючерсная
история глубже (BTC с 2019-09 против 2021-07: +1.9 года; ETH +1.6; ADA +1.5),
что заодно снимает вопрос о трёхнедельном запасе по воротам «годы».
Собирается в `public/data/history-perp`; спотовый корпус НЕ тронут.

⚠️ **Подмена корпуса = граница эпохи, а не правка**: прошлые 56374 испытания
станут измерениями другого рынка. Требует решения владельца; после подмены —
пометить эпоху, поднять GATE_VERSION, перепрогнать три финансируемых
семейства на перпах. `binance.ts` (живая догонка) тоже перевести на fapi,
иначе паритет сломается.

### ⚠️ Известные дефекты, ещё НЕ починенные
- **Пространство финансируемых семейств ИСЧЕРПАНО**: 936 из 936 (468 × 2 ТФ).
  Ночи будут падать на предохранителе, пока новое семейство не получит
  пре-регистрацию с «кто платит». Это правильное поведение, а не поломка.
- **Планка DSR требует годового Шарпа ≈5**: nEffective берётся из ВСЕГО
  журнала (9640 кластеров), из них **2780 (28.8%) — фантомные 1d-кластеры**
  (метка ТФ была фикцией, прогоны шли по 1h/4h). Максимальный DSR за всю
  историю — 0.3278 при пороге 0.95. Часть «0 находок из 56370» — арифметика
  планки, а не свойство рынка.
- **Ворота Уилсона и OOT НИ РАЗУ не исполнялись** (0 записей в журнале) —
  непроверенный на живых данных код.
- **Инкубатор не отработал ни одного цикла**: incubations = 0, paper_trades
  = 0 за всю историю.
- Ворота Уилсона слишком МЯГКИЕ: сделки перекрываются во времени, а интервал
  считает их независимыми (нужны веса уникальности 1/concurrency).
- gate_temporal считает огрызки лет полноценными (2021 = 5.5 мес).
- Lookahead в тирах ликвидности (corpus.ts: 180 дней 2025 → вся история).
- Фандинг не начисляется в PnL; издержки — одна плоская ставка на вселенную.
