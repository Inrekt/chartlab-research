# Состояние проекта — для любой новой сессии (обновлено 2026-11-07, поздний вечер)

Этот файл — точка входа для сессии Claude, начатой с нуля (например, с
телефона через claude.ai/code). Прочитай его и learning-machine-v3.md (с
дополнениями) прежде чем что-либо делать.

## Что это

Автономный исследователь торговых стратегий (ЛИЧНЫЙ проект владельца, не
Zenta Fund). Цель: найти края с настоящим механизмом, прогнать через 9 ворот
и инкубатор, выдавать владельцу сигналы для ручной торговли на проп-аккаунте
(целевая фирма — Breakout 1-Step Classic; риск 0.25%/сделку).

## Незыблемое (нарушать нельзя ни при каких просьбах)

- Пре-регистрация семейства ДО кода, с полем «кто платит».
- Неприкасаемые ворота: нуль-модель, FDR, годы, дефляция, Уилсон, OOT,
  широта. НЕ ослаблять ради «валидаций». Файрвол обучения не трогать.
- Слепой перебор индикаторов заморожен навсегда (политика whoPays).
- Коммитить только свои файлы явным списком; общий код синхронизировать
  research → основной (/Users/user/Desktop/chartlab, там UI).
- Прод-деплой — только с явного подтверждения владельца.

## Состояние (2026-11-07, ночь) — вечера 11–12: «мозг» (ветка `feat/brain`)

Машина сама предлагает идеи от механизма, а не от перебора кубиков.

- `mechanisms.ts` — каталог «кто платит»: 11 механизмов (стопы за уровнем,
  ликвидации, фандинг ×3, открытие сессий, ребалансировка, разлоки, толпа против
  китов, запертые новые позиции, поглощение агрессора). У каждого: данные,
  триггер, направление, естественный выход, ТФ, грубые априорные частота и край.
  Статусы: `open` / `refuted` / `closed` (со ссылкой на опровержение) /
  `in_grammar` (funding_pressure) / `in_progress` (ордерфлоу).
- `brain.ts` — генератор механизм × набор кубиков × ТФ (только `open`) и проверки:
  плательщик, данные на диске, кубики в ядре (мягкая), ≥200 сделок в окне и
  ≥5 на символ, мёртвый срез «семейство × ТФ» в журнале (≥20 испытаний, 0
  выживших), край ≥ пола издержек (`cost-floor.ts`, σ сделки замер 1h/4h, 1d по
  √времени). Свинг вперёд.
- Таблица `hypotheses` в `ledger.ts` (схема v4): пре-регистрация пишется при
  вставке и неизменна (триггер), статус только proposed → queued | rejected.
  **Множественность:** proposed планку не поднимает; queued входит в F
  (`familiesTried` = объединение семейств журнала и поставленных гипотез, без
  двойного учёта). Ставит только `promote`: авто-одобряемое (все кубики в ядре,
  все проверки, не воскрешение опровергнутого), лимит 1 за ночь.
- `hint.ts "текст"` — наводка по ключевым словам → те же проверки; опровергнутый
  механизм только с `--new-hypothesis`, и тогда не авто-одобряем. Ollama не
  подключена.
- Сегодня на настоящем корпусе: авто-годны «запертые новые позиции»
  (oiChange+funding, 4h и 1d), предложение — поперечный фандинг (нужен
  `crossSectionRank`), отсеяны сессии и ребалансировка (пол издержек), разлоки

- Проверено: `npm test` 69 файлов / 658, typecheck чистый (два старых теста
