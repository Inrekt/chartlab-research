# Состояние проекта — для любой новой сессии (обновлено 2026-08-07)

Этот файл — точка входа для сессии Claude, начатой с нуля (например, с
телефона через claude.ai/code). Прочитай его и learning-machine-v3.md (с
дополнениями) прежде чем что-либо делать.

## Что это

Автономный исследователь торговых стратегий (ЛИЧНЫЙ проект владельца, не
Zenta Fund). Цель: найти края с настоящим механизмом, прогнать через 9 ворот
и инкубатор, выдавать владельцу сигналы для ручной торговли на проп-аккаунте
(целевая фирма — Breakout 1-Step Classic; риск 0.25%/сделку).

## Незыблемое (нарушать нельзя ни при каких просьбах)

- Пре-регистрация семейства ДО кода, с полем «кто платит».
- Неприкасаемые ворота: нуль-модель, FDR, годы, дефляция, Уилсон, OOT,
  широта. НЕ ослаблять ради «валидаций». Файрвол обучения не трогать.
- Слепой перебор индикаторов заморожен навсегда (политика whoPays).
- Коммитить только свои файлы явным списком; общий код синхронизировать
  research → основной (/Users/user/Desktop/chartlab, там UI).
- Прод-деплой — только с явного подтверждения владельца.

## Где что

- Этот репозиторий (chartlab-research) — источник истины researcher/ и
  src/core; его гоняет GitHub Actions (nightly 21:37 UTC, hourly, collect).
- Журнал испытаний: приватный repo chartlab-research-data (на маке зеркало
  ~/.chartlab/data-repo). 56k+ испытаний, 0 валидаций — это диагноз
  выжженного поля индикаторов, а не поломка.
- Данные: свечи 1h/4h со 170 перпов (2020+), фандинг (2020+), почасовые
  OI/long-short/taker (2020-09+, добэкфилено 2026-08-07), DVOL, F&G, FRED.
- Экран: вкладка «Хедж-фонд → Исследователь» в основном репо.

## Состояние (2026-08-07)

Фаза 1 обучающейся машины ЗАВЕРШЕНА: metrics-1h добэкфилены (169 монет),
атомы takerFlow + CVD-дивергенция, срез вселенной по ликвидности, вскрытия
(depth-score + таксономия) с файрволом, фандинг понижен вход→условие,
GATE_VERSION=4, политика бюджета whoPays.

В работе (по порядку):
1. Фундаменты событий: collect-events.ts (exchange-snapshot работает;
   announcements --backfill и lifespans дозапустить; wire в collect.yml;

   DefiLlama платные — ищем бесплатный источник.
2. СВИП-СЕМЕЙСТВО (флагман, край владельца) — пре-регистрация до кода.
3. Чат гипотез (дизайн-док, потом вкладка UI): ответы по журналу + приём
   наблюдений владельца с «кто платит», датой до прогона; чат не может
   трогать ворота.
4. Обработка ресёрча «каталог семейств / макро / квант-метрики» (воркфлоу

Очередь семейств после свипа: unlock-short (ждёт данных), пост-листинг
фейд, expiry-week × свип.

## Локальный мак (из облака недоступен)

Охотник за ёмкостью Oracle A1 (~/.oci/launch-chartlab.sh) — проверять
pgrep -f launch-chartlab.sh. Бэкфиллы и Obsidian-вольт — тоже локальные.
Сессии с телефона: работать с репозиторием можно, с маком — нельзя.

## Проверки перед коммитом

research: npm run typecheck && npx vitest run (+ screen --n 200 при правках
воронки). Основной: npx tsc -b && npx vitest run.

## Владелец

Торгует руками в плюс (шорт перерастянутости к скоплениям ликвидности, стоп
за всей ликвидностью, добор на дальних уровнях). Общение — простым языком,
без жаргона; честные числа важнее оптимизма. Решения владельца — списком в
конце ответа.
