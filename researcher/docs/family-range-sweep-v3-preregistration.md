# Пре-регистрация: свип v3 — вход первой версии плюс сопровождение

**Дата: 2026-08-09. Записано ДО кода.** Заморожено отдельным коммитом.

## Единственная непроверенная комбинация

Две версии прогнаны, и обе оставили дыру ровно посередине:

| | фильтр «цель существует» | сопровождение (тейк частью + БУ) | результат |
|---|---|---|---|
| v1 | **есть** | нет (движок не умел) | 0 из 108, до издержек +0.0245R на 1ч |
| v2 | нет | **есть** | 0 из 216, до издержек −0.0360R на 1ч |
| **v3** | **есть** | **есть** | не проверялось |

v2 изменила ДВЕ вещи одновременно — это моя ошибка постановки опыта, и она
стоила семейства в бюджете проб. v3 исправляет её единственно возможным
честным способом: берёт вход v1 без единого изменения и добавляет ровно одну
новую вещь.

## Почему это не «ещё одна попытка», а проверка конкретной гипотезы

Гипотеза формулируется до прогона и проверяема:

> Фильтр «цель существует» отбирает сделки, у которых впереди есть куда идти.
> Сопровождение спасает те из них, что сначала пошли верно, а потом развернулись.
> Механизмы разные и не пересекаются, поэтому вместе они должны дать больше,
> чем поодиночке.

Основания считать так, оба замерены ЗАРАНЕЕ:
- фильтр держит матожидание до издержек в плюсе (+0.0245R на 1ч у v1 против
  −0.0360R у v2 без него);
- 78% убыточных сделок v1 сначала уходили в плюс на 0.3R — то есть материал
  для спасения безубытком там есть.

**Если гипотеза неверна, результат будет не лучше v1.** Это и есть проверка.

## Что именно берётся

Вход, сетка, выходы, длины окна, направления, таймфреймы — ТОЧНО как в v1,
байт в байт. Единственное добавление:

```
scaleOut = { atR: 0.5, fraction: 0.5, toBreakeven: true }
```

Половина позиции снимается на 0.5R, стоп переносится к средней цене входа.
Значение одно, не сетка — по той же причине, что и в v2: разведка показала
нечувствительность результата к уровню (0.3/0.5/1.0R близки), и тратить на
него бюджет проб значило бы поднять планку всему семейству ни за что.

Размер: 54 комбинации на ТФ, 108 на два — как у v1.

## Ожидаемый эффект, зафиксированный ЗАРАНЕЕ

- Матожидание до издержек на 1ч: **+0.05…+0.12R** (v1 дал +0.0245R без
  сопровождения; безубыток обязан добавить, раз 78% убытков были спасаемы).
- Валидированных: **0–2**. Больше двух — повод заподозрить ошибку, а не удачу.
- Число сделок НЕ меняется относительно v1: вход тот же. Если изменилось —
  значит вход тронут, и прогон недействителен.

Последний пункт — самопроверка: он ловит случай, когда я по невнимательности
задел вход.

## ⚠️ Заранее объявленное правило остановки

**Если v3 даёт ноль валидированных, версии свипа исчерпаны.** Дальнейшее
возвращение к этому семейству допускается только с НОВЫМ МЕХАНИЗМОМ — новой
причиной, по которой кто-то обязан платить, — а не с новой комбинацией уже
испробованных частей. Перебор комбинаций собственных прошлых попыток и есть
подгонка, просто медленная.

Это правило записано ДО прогона намеренно: после отрицательного результата
соблазн «попробовать ещё вот так» максимален, и остановить его может только
обещание, данное заранее.

## Чего v3 НЕ делает

Не трогает ворота, пороги, издержки, пул выходов, длины окна, условия входа.
Не добавляет атомов. Не пересматривает v1 и v2 — их вердикты остаются в
журнале как есть.
