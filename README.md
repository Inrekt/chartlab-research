# chartlab-research

Автономный исследователь торговых стратегий: закрытая грамматика из 666 792
кандидатов «сетап × подтверждения», ночной гаунтлет из девяти ворот с
дефляцией на число попыток (DSR), форвард-инкубатор SPRT на живых барах и
пожизненный надзор CUSUM. Решения принимает только считаемая статистика —
ни одной нейросети в контуре.

**Здесь публичен метод.** Журнал испытаний, дайджесты и карточки найденных
стратегий пишутся в приватный репозиторий: воспроизводите метод на своих
данных, а не копируйте чужие результаты.

- `researcher/` — грамматика, append-only журнал, ворота, SPRT, CUSUM,
  самокалибровка; тесты рядом с каждым модулем (`npm test`)
- `src/core/` — движок бэктеста, evaluator условий, индикаторы, модель
  издержек (общие с терминалом ChartLab)
- `public/data/history/` — корпус закрытых свечей Binance (1h/4h, 170 пар)
- `.github/workflows/` — ночной перебор и ежечасная догонка инкубатора

Честные ожидания: из 1 000 идей ворота пропускают 0–2, первые выпускники
требуют 4–6 месяцев живой проверки. Система, «выпускающая» чаще, — сломана.
